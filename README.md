# zqq-015 · 成语字源与语义DNA图谱

纯前端成语字源考据与语义拓扑分析系统。用户输入任意成语，系统拆解为四字金石甲骨字形溯源、典故出处时间轴与原文引证、语义流变路径，并测算生成该成语的"语义DNA"（本义/引申义/比喻义占比环形图及核心义原），支持任意两个成语的语义亲缘度交叉比对演算，并可生成两词条的**语义演化对比报告**（共同祖义、分叉时期、现代差异三段式考据，支持重新选择与导出）。

## 架构说明（分层架构：核心层 / 端口层 / 适配器层）

- `src/core`：领域模型（`OracleChar`、`AllusionSource`、`SemanticEvolutionStep`、`SemanticDNA`、`IdiomProfile`、`KinshipResult`、`EvolutionComparisonReport` 等）与欧氏DNA几何距离、义原Jaccard相似度算法；`evolution-report-engine.ts` 负责共同祖义推定、三阶段（本义/引申义/比喻义）对齐与分叉演算、现代差异归纳，并收集全报告的缺失/存疑/无考字段；`report-export.ts` 提供 Markdown 与独立 HTML 两种导出。
- `src/ports`：端口层契约（`IdiomRepositoryPort` 典籍成语检索端口、`KinshipPort` 亲缘度比对端口、`EvolutionReportPort` 演化报告生成端口）。
- `src/adapters`：适配器层（内置甲骨文字典与通用汉字语义生成适配器、亲缘比对分析适配器、演化报告适配器）。
- `src/ui`：原生 CSS 宣纸墨韵古典视觉呈现层，包含金石甲骨卡片、历史时间轴、语义DNA甜甜圈图表、双词亲缘竞技场与语义演化对比报告视图（`report-view.ts`）。

## 语义演化对比报告

顶部切换至「语义演化报告」标签，选择两个词条（支持典范成语快捷配对或自行输入）后生成报告：

1. **共同祖义**：并列两词本义、共有核心义原与极性，给出祖义推定与置信度（高/中/低/不可考）。
2. **分叉时期**：本义→引申义→比喻义逐阶段对齐表（时代、义项、文本相似度、对齐判定），标出首次分叉的阶段与时段区间。
3. **现代差异**：现代释义、感情色彩、句法功能、各自独有义原的对照与归纳。
4. **缺失字段总目**：所有 `【缺失】` / `【存疑】` / `【无考】` 字段按归属、栏目、原因显式列出（通用推演词条会被自动标注为存疑；分叉精确年代因语义渐变为连续过程而标注无考）。

报告页提供「重新选择」（回到选择页并保留上次输入）、「导出 Markdown」「导出 HTML」（独立样式单文件）操作。
